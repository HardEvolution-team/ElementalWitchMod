# Elemental Witch Mod Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **Elemental Witch Mod** by its original author (mwaw).

- Original: https://www.9minecraft.net/?p=76811
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.27.0+

This port contains **no original assets**. Put your own copy of the original jar (`mwaw_1.7.10_0.0.3.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures/sounds from it at runtime.
